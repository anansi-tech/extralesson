The queue keeps its shadow; nothing else on the page has one. It is the only card here, so it is the only thing that can be the work.

A reason is asked for after the action is chosen, not before — the field beside a button you have not pressed is a field you read past. The one exception is waiting, where the primary needs an address, not a reason: the address is the decision.

A closed row has no inputs in it at all. Six accounts used to mean up to eighteen form fields at rest; now it means six lines and a state word.

Three state words only — access, free used, revoked — at a fixed width so the column reads straight down. Green for access, red for the two that need a decision eventually.

One open at a time is behaviour, not markup: opening a second row closes the first, so the page never grows under your thumb while you read it.

Label-value pairs, not sentences. A grant is four facts; as prose you read all of it to find the one you wanted. The label column is set to its content, so the values line up however long the words are.

The three variants differ only in the last block. Paid gets the ink primary; a comp and an unreferenced payment both get the outline Revoke — one because there is no money, the other because the money cannot be reached from here.

The warning sits above the control it limits, not beside it: you need to know the refund is unavailable before you decide that revoking alone is the right move.
