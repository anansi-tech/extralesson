# Hints

A second-person sentence for every method row, shown to a student who got
the slot wrong, in place of the criterion. Generated by script from the
criterion in batches of 200 (`pnpm hints:generate <batch>`), written here
as proposed, approved by hand in `APPROVAL_LOG.md`, and applied to the bank
by `pnpm hints:approve <batch>`. Only an approved hint is ever rendered.

- `batch-N.json`: `{ question_id, code, criterion, hint, status }` per row,
  in bank order (question id, then rubric order).
- `APPROVAL_LOG.md`: one table per batch; a row is approved by setting its
  status in the JSON to `approved`, or rewritten by editing `hint` first.
